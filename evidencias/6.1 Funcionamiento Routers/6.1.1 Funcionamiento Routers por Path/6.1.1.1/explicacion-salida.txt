Hostname: ID del contenedor Docker que procesó la petición. Si tuviesemos replicas, veríamos cómo este valor cambia con cada request, demostrando el balanceo de carga.
Headers que agrega Traefik: Al actuar como reverse proxy, Traefik inyecta headers que informan al servicio backend los datos originales de la petición, ya que el contenedor no recibe la conexión directa del cliente sino de Traefik. Entre ellos: X-Forwarded-For (la IP pública real del cliente), X-Forwarded-Host (el dominio solicitado), X-Forwarded-Proto (el protocolo original, HTTP o HTTPS), X-Forwarded-Port (el puerto de entrada) y X-Forwarded-Prefix (el prefijo del path original, útil cuando se aplica StripPrefix).
IP (127.0.0.1, ::1, 172.19.0.5): Son las direcciones IP propias del contenedor whoami.
RemoteAddr (172.19.0.6:57950): Es la IP de quien se conectó directamente al contenedor. Nosotros como clientes que hicimos curl a esa url, realmente no es la ip que se va a mostrar, sino que como se esta haciendo reverse proxy, esa ip es la del contenedor traegik.
